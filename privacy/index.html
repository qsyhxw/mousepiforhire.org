Overview

This policy is tied to the site as it is currently implemented

MousePIForHire.org is an independent fan guide for MOUSE: P.I. For Hire. This privacy policy is written around the site implementation reviewed on April 29, 2026. Information You Provide

What the site may receive directly from you

If you contact MousePIForHire.org using the current contact address, the site may receive the information you choose to include in your email. That can include your email address, your message, page URLs you mention, patch or platform context you provide, and any other details you include voluntarily.

Third-Party Resources

What happens when pages load external resources

The reviewed pages currently load Google Fonts from the Google Fonts Web API and styling resources through the Tailwind browser CDN. That means your browser makes requests to those third-party services when the page loads those resources.

Google's public documentation for Google Fonts says the Google Fonts Web API does not set or log cookies and that font requests include technical request data such as the visitor IP address, requested URL, and HTTP headers like user agent and referer.

The site also currently loads Tailwind through the browser CDN. That external request is part of the page rendering path as currently implemented. If the site later moves those resources fully local, the privacy surface for page loading would become narrower.

Current External Loads

  • Tailwind browser CDN script
  • Standard page assets hosted on the site itself

Cookies, Ads, and Analytics

What this policy says about them right now

In the reviewed site files, no active analytics tag such as a Google Analytics script was found in the current page templates. That means this policy does not currently describe a live analytics implementation on the reviewed pages.

The reviewed HTML does include a Google AdSense placeholder path in the template set. Because repository state and live deployment can change over time, this policy is written so that ad-related disclosure expectations are already visible and can be tightened further as live ad behavior changes.

Google's AdSense documentation says that when pages include Google ad tags, AdSense can use cookies and publishers must notify users about that cookie use in their privacy policy. If MousePIForHire.org later enables live Google ads or similar ad technology, this section should be revised to reflect the real ad stack in use at that time.

How information is used under the current site model
